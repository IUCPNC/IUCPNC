Sync controls

Changes are checked approximately every minute after activation. Busy runs, large batches and Google limits can take longer. The browser can be closed.

Connection setup
  1. In the master Sheet, open Extensions → Apps Script using the authorised HR Google account.
  2. Preserve existing workbook scripts and add the Google runner script and its manifest settings (merge them with any existing settings).
  3. The Site administrator sets SHEETS_SYNC_RUNNER_KEY as a private Site environment variable. In Apps Script project settings, save the matching SYNC_RUNNER_KEY and the Site's private SITES_SERVICE_TOKEN as Script Properties. Keep these credentials out of Sheet cells and source code.
  4. Run installIucSync once and authorise Google access. This verifies the connection and installs one minute-based trigger.
  5. Return here, refresh status and enable automatic sync. Valid changes transfer automatically. No per-record approval is required.

Access to Google Drive in a chat does not grant this published Site permission to read or update the Sheet.

Sync exceptions

Edits to different fields are merged. If the same editable field changes on both sides, the Google Sheet wins. Job title and other work details controlled by an active primary appointment follow the approved position instead. The Admin tab contains automatically maintained shared position, employee appointment, published JD / TOR and committee / project registers. These registers are maintained in their owning Site workflows and do not create extra spreadsheet tabs. Existing populated values are preserved during initial reconciliation when the other side is blank. Invalid data and transfer errors retry automatically; correct their source instead of approving a transfer. Deleting a previously synchronised editable row removes it from the Site on the next successful check. Deleting an Employee Master row archives the employee and disables their access; HR and MPC history is retained. MPC results and document files remain managed in their own workflows.
